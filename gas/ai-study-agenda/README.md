# AI勉強会 アジェンダ自動追加（Google Apps Script）

「AI Park イベント」カレンダーにタイトルへ「AI勉強会」を含む予定を登録すると、10分以内に予定の説明欄へアジェンダが自動で追加されます。アジェンダには AI Park の最新状況（ご意見・社内AIプロジェクト・取材立候補・アンバサダー応募）が GitHub から反映されます。

## 1. 「AI Park イベント」カレンダーを作る（社内アカウントで）

1. Google カレンダー左側「他のカレンダー」の「＋」→「新しいカレンダーを作成」
2. 名前：`AI Park イベント` →「カレンダーを作成」
3. 作成したカレンダーの設定を開き、「アクセス権限」で **組織内（ml-mightylink.com）で公開** をオンにする（「予定の表示（すべての予定の詳細）」を選ぶ）
   - 「一般公開して誰でも利用できるようにする」はオンにしない（社外に予定が見えてしまうため）
4. 同じ設定画面の「カレンダーの統合」にある **カレンダー ID** をコピーしておく

## 2. スクリプトを設置する

1. https://script.google.com を社内アカウントで開き「新しいプロジェクト」
2. プロジェクト名を `AI勉強会アジェンダ` に変更
3. `コード.gs` の中身をすべて消し、このフォルダの `Code.gs` の内容を貼り付ける
4. 先頭の `CALENDAR_ID: ""` の `""` の中に、手順1-4でコピーしたカレンダー ID を貼り付けて保存
5. 左の「プロジェクトの設定（歯車）」→「「appsscript.json」マニフェスト ファイルをエディタで表示する」をオン → エディタに出た `appsscript.json` の中身を、このフォルダの `appsscript.json` に置き換えて保存

## 3. 動作確認と定期実行の登録

1. 上部の関数選択で `addAgendaToStudySessions` を選び「実行」
   - 初回は権限の確認画面が出る →「権限を確認」→ 社内アカウントを選択 →「許可」
2. 「AI Park イベント」カレンダーに `AI勉強会（テスト）` のような予定を作り、もう一度「実行」→ 予定の説明欄にアジェンダが入れば成功（確認後テストの予定は削除）
3. 関数選択で `setupTrigger` を選び「実行」→ 以後10分ごとに自動で確認されます

## 運用メモ

- アジェンダは1つの予定につき1回だけ追加されます。作り直したいときは説明欄の `【アジェンダ（自動生成）】` 以降を削除してください（次の定期実行で最新の状況で作り直されます）。
- 対象は「今から60日先まで」の予定です（`LOOKAHEAD_DAYS` で変更可）。
- 定期実行を止めるときは、スクリプト画面左の「トリガー（時計）」から削除します。
- サイトのカレンダーページ（/calendar）に表示するには、カレンダー ID を AI CoE に伝えてください。
