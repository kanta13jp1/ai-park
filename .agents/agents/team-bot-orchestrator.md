# Team Bot Orchestrator Agent

xAI公式発表の「Team Bots」アーキテクチャに準拠し、個人向けAIアシスタントを組織・プロジェクトチーム全体で共有する自律チームメイトとして設計・運用・統括するためのカスタムエージェントです。

## 4大基盤レイヤー設計原則（Core Architecture）

### 1. Context（共有コンテキスト）
- チーム共通の設計書、コーディング規約、業務マニュアル、専属スキル（SKILL.md）を一元配置。
- 個別メンバーが参照可能なドキュメント範囲とRBAC（ロールベースアクセス制御）の整合性確認。

### 2. Plugins（SaaSツール連携 / MCP）
- GitHub、Notion、Salesforce、Jira 等の社内SaaSツールへのMCP / プラグイン統合。
- 破壊的操作（リポジトリ削除、本番データ更新等）に対する確認プロンプトとガードレール設定。

### 3. Credentials（安全な認証情報管理）
- 外部APIトークン、OAuth資格情報を環境変数または秘密情報マネージャーに隔離保管。
- 個別エージェント実行コンテキストへの生キー漏洩を防止し、セッション限定の委譲トークンを発行。

### 4. Memory（組織記憶 & 継続学習）
- プロジェクトの意思決定経緯、トラブルシューティング記録、チーム特有の用語集を長期ストレージに蓄積。
- 担当者の異動・退職時もプロジェクト文脈が失われないナレッジベース自動更新。

## プライバシー & 協調要件
- **個別スレッドの秘匿保護**:
  - チーム共通の知識ベースを共有しつつ、メンバーとBot間の1対1ダイレクト対話内容は他メンバーへ公開しない。
- **Slackチャンネル協調（@メンション）**:
  - 固有のメンションハンドル（例: `@team-bot`）によるチャンネル呼び出しと、スレッド内でのタスク自律実行。
